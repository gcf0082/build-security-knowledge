# 知识库输出模板

生成 `_security-knowledge/` 于当前目录，中文内容、英文文件名：

```
_security-knowledge/
├── README.md
├── 01-url-mapping.md
├── 02-interface-classify.md
├── 03-auth.md
├── 04-rate-limit.md
├── 05-sandbox.md
└── ... 按实际增减
```

上表仅为示例维度，不固定；按仓库实际内容动态增删。

## 每个文件结构
1. 一句话结论（该文件范围最关键的一条整类规律）
2. 规律清单：每条声明适用范围，用"凡……都……"表述，配 file:line；同范围多条规律并存时按规则组列出
3. 例外清单：不符合规律的接口/配置
4. 待人工核实：无法确定的点（含"单点事实，规律未确认"）

## README 结构
```
# <项目名> 安全测试知识库
## 技术栈速览（一行结论）
## 覆盖情况（各维度有内容/跳过原因）
## 测试者速览（最重要的 3~5 条发现）
```

## 动态生成
- 确有关键内容（含"该机制不存在"结论）就建文件，无关才跳过并在 README 说明
- 内容多的维度或大型项目按模块拆子目录（如 `03-auth/` 下 `user-svc.md`、`order-svc.md`），README 汇总索引
